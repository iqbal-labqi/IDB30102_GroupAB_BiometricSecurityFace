# Evaluation Metrics

| Metric | Purpose |
|---|---|
| APCER | Measures the error rate of attack presentations accepted as genuine |
| BPCER | Measures the error rate of genuine presentations rejected as attacks |
| ACER | Provides the average error rate between APCER and BPCER |
| Execution Latency | Measures the processing time of the system |

The proposed framework will be compared with the selected baseline 
using the same dataset and experimental conditions.
