# Expected Results

The proposed framework will be evaluated to determine whether it provides better protection against facial presentation attacks compared with the selected baseline model.

The evaluation will focus on presentation attack detection accuracy 
and processing efficiency.

The expected comparison will consider:

- APCER
- BPCER
- ACER
- Execution latency

Lower error rates are expected to indicate better spoof detection 
performance, while reasonable execution latency will indicate that 
the proposed framework remains suitable for lightweight deployment.
