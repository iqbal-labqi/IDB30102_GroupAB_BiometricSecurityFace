# Architecture and Flowchart

This folder contains the proposed system architecture and flowchart for the lightweight, privacy-preserving facial biometric authentication framework.

## Contents

### `Figure 1.png`
Proposed system architecture showing the main processing stages of the facial biometric authentication framework:

Facial Input → Preprocessing → Presentation Attack Detection → Feature Processing → Privacy Protection → Face Matching → Authentication Decision

### `Figure 2.png`
Proposed system flowchart showing the sequence of an authentication attempt, including the liveness check and the decision to accept or reject the input.

## Purpose

The diagrams illustrate the proposed system structure and processing flow described in Chapter 3 of the Research Proposal.

The architecture and flowchart are proposed designs and may be refined during the development and experimental stages.
