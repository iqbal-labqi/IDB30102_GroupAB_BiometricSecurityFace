# 01 — Research Papers

This folder contains the research-paper evidence used for the proposal literature review. The selected studies are compiled directly from the group's 48-paper Literature Review Findings Table.

The compiled list uses the required fields for each paper:

- Paper Title
- Author(s)
- Year
- Research Problem
- Method / Technique
- Dataset / Tools
- Main Findings / Results
- Limitation
- Relevance to Proposed Research
- DOI / Official Link

No copyrighted research-paper PDF files are included in this folder. The official source / DOI shown for each paper follows the links provided in the group's supplied reference material.
