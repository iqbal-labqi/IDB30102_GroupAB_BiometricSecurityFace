# Dataset Description

## Selected Dataset

The study will use a public facial anti-spoofing benchmark dataset. 
OULU-NPU will be considered, with the final dataset 
selected based on its suitability for the proposed experiment.

## Dataset Purpose

The dataset will provide genuine facial samples and presentation 
attack samples for testing the proposed facial biometric 
authentication framework.

## Intended Use

The dataset will be used to evaluate presentation attack detection 
performance and compare the proposed framework with the selected 
baseline model.

## Data Preparation

The selected data will be prepared using the recommended dataset 
protocol before being used in the experiments.

## Dataset Source

The official dataset source and DOI will be provided after the final 
dataset has been selected.

## Important Note

The original dataset will not be uploaded to this repository if its 
distribution is restricted. Only dataset information and permitted 
sample materials will be included.
