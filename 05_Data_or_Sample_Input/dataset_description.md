# Dataset Description

## Selected Dataset

The study will use the OULU-NPU public facial anti-spoofing benchmark
dataset for the proposed experimental evaluation.

## Dataset Purpose

The dataset provides genuine facial samples and presentation attack
samples for testing the proposed facial biometric authentication
framework.

## Intended Use

The dataset will be used to evaluate presentation attack detection
performance and compare the proposed framework with the selected
baseline model.

## Data Preparation

The selected data will be prepared using OULU-NPU's recommended
protocol (Protocols I–IV) before being used in the experiments,
allowing evaluation across different illumination conditions, capture
devices, and presentation attack instruments.

## Dataset Source

- **Name:** OULU-NPU: A Mobile Face Presentation Attack Database with
  Real-World Variations
- **Citation:** Boulkenafet, Z., Komulainen, J., Li, L., Feng, X., &
  Hadid, A. (2017). OULU-NPU: A mobile face presentation attack
  database with real-world variations. In *2017 12th IEEE
  International Conference on Automatic Face & Gesture Recognition
  (FG 2017)* (pp. 612–618). IEEE.
- **DOI:** https://doi.org/10.1109/FG.2017.77
- **Access:** The dataset is not publicly downloadable without
  request. Access must be requested directly from the dataset
  providers (Center for Machine Vision and Signal Analysis,
  University of Oulu) via their official request process. This
  repository will not host or redistribute the raw dataset.

## Dataset Overview

- 4,950 real access and attack videos from 55 subjects
- Captured using 6 different mobile device front cameras
- Includes print and video-replay presentation attacks
- Organized into 4 evaluation protocols to test generalization across
  unseen illumination, capture devices, and attack instruments —
  directly relevant to this research's cross-domain evaluation focus

## Important Note

The original dataset will not be uploaded to this repository, as its
distribution is restricted to the official request process described
above. Only dataset information and permitted sample materials will
be included here.
